HP DeskJet 5900 series driver for Apple silicon

A native arm64 build of HP's open-source hpcups printer filter (from HPLIP 3.26.6) with HPLIP's DeskJet 5900-series PPD, for the DeskJet 5938, 5940, 5940xi and 5943. It doesn't need Rosetta.

It installs to /Library/Printers/hplip-arm64 and adds one PPD so the printer can be picked in System Settings. It doesn't change any security settings or other HP software.

This is an unofficial community build, not supported by HP or Apple.
