Next: add the printer

  1. Connect the printer by USB. Open System Settings → Printers & Scanners → Add Printer.
  2. Select the DeskJet 5900 series. Under Use, choose Select Software… and pick HP Deskjet 5900 Series, hpcups 3.26.6 (arm64).

Queue pauses with "Unable to use legacy USB class driver."?

An old HP driver on this Mac left kexts in /Library/Extensions that force the printer onto an Intel-only USB plugin. To check, and fix it if needed, run this in Terminal:

/Library/Printers/hplip-arm64/fix-hp-usb-classdriver.sh
sudo /Library/Printers/hplip-arm64/fix-hp-usb-classdriver.sh --fix

Then reboot. You can undo it with --restore.

To uninstall: sudo /Library/Printers/hplip-arm64/uninstall.sh
